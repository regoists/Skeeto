Skeeto 贴图准星 DIY 教程
==============================

Skeeto 有静态准星、动态散布圈和贴图准星三种路径。只有贴图准星读取外部
VMT/VTF；静态准星由 Win32 绘制，动态准星由引擎 HUD 绘制，二者不是贴图也不能换贴图。


一、素材目录
------------

推荐在 VPK 中使用：

  materials/skeeto/xhair/my_crosshair.vmt
  materials/skeeto/xhair/my_crosshair.vtf

菜单会扫描 materials/skeeto/xhair 下的 VMT，最多列出 64 个材质。文件名会
用于菜单识别，建议只使用小写英文、数字和下划线。


二、最小 VMT
------------

"UnlitGeneric"
{
    "$basetexture" "skeeto/xhair/my_crosshair"
    "$translucent" "1"
    "$vertexalpha" "1"
    "$vertexcolor" "1"
}

$basetexture 从 materials/ 后开始写，不带 .vtf 扩展名。VMT 与 VTF 文件名
可以不同，但引用必须准确。VMT 建议保存为无 BOM 的纯文本。


三、纹理制作建议
----------------

- 使用带 Alpha 的正方形纹理，准星中心严格位于画布中心。
- 推荐 64、128、256、512 等 2 的幂尺寸；通常无需使用超高分辨率。
- 透明区域不要残留白色或黑色脏边，避免缩放后出现轮廓。
- 线条过细会在缩放时闪烁，过粗会挡视野；应在实际分辨率中检查。
- 只保留运行需要的 VMT/VTF，不把 PSD、预览图或编辑缓存打进 VPK。


四、普通模式与铺满屏幕模式
--------------------------

普通模式把贴图作为居中的准星绘制，菜单可单独记忆每个 VMT 的大小。
铺满屏幕模式适合本身按整张屏幕构图的瞄准覆盖层，不适合普通小准星。
同一素材应分别测试两种模式，确认默认模式不会意外放大挡住画面。


五、叠加关系
------------

原版准星、Skeeto 静态准星、动态散布圈和贴图准星可以同时存在，因此出现
两个或多个标记不一定是素材故障。静态准星作为外置叠加层，可能画在贴图
准星上方。Skeeto 不会自动替用户修改原版 crosshair 设置。


六、打包与测试
--------------

1. 保持 materials/skeeto/xhair/... 的相对结构打成 addon VPK。
2. 启用 VPK，进入 Skeeto 的贴图准星页面循环材质。
3. 测试 16:9、16:10、4:3 和窗口/全屏模式下是否始终居中。
4. 测试大小调节、每材质记忆、普通模式和铺满屏幕模式。

如果从其它准星 Mod 改造，复制其 VMT/VTF 后必须同时修改文件名与
$basetexture 路径，不能只改外层文件名。
