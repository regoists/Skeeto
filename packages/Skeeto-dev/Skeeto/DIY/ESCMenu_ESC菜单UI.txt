自定义 ESC 菜单 DIY 教程

自定义 ESC 菜单用于进入地图后的游戏菜单。可以添加按钮、文字、ConVar 滑块、飞出子菜单和信息组件，也可以调整位置、大小、颜色与透明度。

ESC 菜单布局、主菜单布局和自定义 HUD 方案互不通用。

1. 开始编辑

在 Skeeto 菜单中进入“自定义游戏UI按钮 → 自定义ESC菜单UI”，开启“自定义 ESC 菜单”。进入地图后按 ESC，即可打开。

也可以在控制台输入：

skeeto_escmenu 1

关闭控制台后，在 ESC 菜单右上角点击“编辑 ESC 布局”。已经有未保存的草稿时，入口会显示“继续编辑草稿”。也可直接输入：

skeeto_escmenu_edit

编辑器左边是布局画布，右边是当前元素的属性。点击元素即可选中；位置太靠近、不方便点选时，使用右侧“元素……打开元素列表”直接选择。

选中元素后，可以修改中文文字、英文文字、动作、动作参数、所属菜单、显示状态、颜色和字号。文字与参数通过系统输入框填写，可以直接输入中文或粘贴。

例如，做一个静音按钮：

- 中文文字：游戏静音
- 动作：控制台命令。（原版ESC菜单指令只能绑定ConVar，无法执行ConCommand。Skeeto的ESC菜单没有这个限制。且ConVar的值使用skt_cvar写入，带特殊flag的cvar过关也不会重置）
- 动作参数：volume 0

完成后点击“应用并保存”。

编辑时点击元素只会选中，不会执行它的游戏动作。按 ESC 暂离编辑时，草稿保留在本次游戏进程中；重新进入可以继续编辑。点击“取消草稿”才会丢弃未应用的修改。尚未应用或保存到槽位的草稿，退出游戏后不会保留。

2. 移动、缩放与对齐

单个元素

- 鼠标拖动元素：移动位置。
- 拖动右下角：调整宽度和高度。
- 方向键：微调位置；按住 Shift 可加大步长。
- X、Y 表示位置，W、H 表示宽度和高度。

画布以 1920×1080 为基准，使用时按屏幕分辨率等比例缩放并居中。这里显示的是布局坐标，不是当前屏幕上的实际像素。按钮、文字和间距一起缩放；超宽屏与 4:3 使用同一套布局，不会自动重新排列按钮。

多选

按住 Ctrl 点击，可以增加或取消选择。最后选中的元素是当前项，右侧属性显示的也是这一项。

拖动已选元素，可以整体移动选区；方向键也会移动整个选区。右下角缩放只改变当前项，要让几项一样大，使用下面的“统一宽高”。多选用于移动和排列，右侧文字、颜色等属性仍只修改当前项。

对齐与尺寸

在编辑器左上角点击“对齐与尺寸”：

- 左边对齐、水平居中对齐、右边对齐。
- 顶边对齐、垂直居中对齐、底边对齐。
- 统一宽度、统一高度、统一宽高。
- 水平等间距、垂直等间距。

对齐和尺寸操作至少选两项，以当前项为基准。统一尺寸仍受元素的最小尺寸限制，滑块不能压到连滑条都放不下。

等间距至少选三项，保留最左与最右、或最上与最下两端的位置，调整中间各项的间隙。空隙按元素边缘计算，不是按中心点计算。空间不够或操作后会超出画布时，不改动原来的位置。

例如，整理左侧一列按钮：

1. Ctrl 点击选中这一列按钮，最后点选位置和尺寸合适的那一项。
2. 点击“对齐与尺寸”，选择“统一宽高”。
3. 再选择“左边对齐”。
4. 调好最上、最下两个按钮的位置，重新多选这一列，选择“垂直等间距”。

多选只在当前菜单页生效。编辑子菜单时，不能跨页选择元素来排列。

吸附

开启左上角“吸附”后，拖动或缩放会靠齐附近元素的边缘、中心和画布边界，出现淡蓝色参考线。没有附近参照时，按 8 个布局单位的网格吸附。

按住 Alt 可以临时停用吸附，也可直接点击“吸附”将其关闭。方向键微调不受吸附影响。普通点击不会自动改变元素的位置。

3. 文字、背景和悬停颜色

文字颜色

可以选择颜色预设，也可以手动输入 RGB。格式为三个 0～255 的整数，用空格分隔：

147 197 253

这个例子是淡蓝色。中文文字和英文文字可以分别填写；英文留空时使用中文文字。文字过长会按按钮宽度截断，想显示完整可以加宽按钮或减小字号。

按钮底色

“按钮底色 / 统一配色 / 透明度”中可以设置：

- 当前按钮背景：只改选中的元素，可以跟随文字颜色、选择固定颜色、完全透明，或使用统一背景。
- 统一背景：修改布局共用的底色；按钮需选择“使用统一背景”才会跟随。
- 所有按钮使用统一背景及透明度：清除各按钮自己的底色和透明度覆盖，统一使用布局设置。

透明度

这里显示的是透明度：0% 不透明，100% 完全透明。默认预设为 95%。

右侧“按钮背景透明度”只改当前项，点击“继承”可恢复使用统一透明度。文字和边框不随背景透明度一起消失；想让全透明按钮也不显示边框，可以关闭“完全透明时显示边框”。

“背景压暗”是整屏背景的压暗程度，与按钮透明度是两项设置。想保留清楚的游戏画面，把背景压暗设为 0%。

悬停边框颜色

默认为“跟随当前按钮颜色”，会跟随按钮的文字颜色，包括手动输入的 RGB。也可以改成琥珀、淡蓝、绿色、紫色、橙色或银白色。这是整套 ESC 布局共用的设置，不是逐按钮设置。

隐藏和删除

- “显示：隐藏”：配置仍保留，正常使用时不显示；编辑器里仍可选中并改回开启。
- “删除元素及全部子项”：删除配置；删除父菜单也会删除里面的子项。
- “复制元素及子项”：复制当前元素；复制父菜单时连同子项一起复制。
- “下移一层 / 上移一层”：调整同一菜单内的顺序，也影响键盘导航和子菜单分页顺序，不是向下或向上移动坐标。

4. 制作飞出子菜单

飞出子菜单是一个容器，本身不用填写动作参数。里面的按钮、滑块、文字通过“所属菜单”归到它下面。

以“音量快捷调节”为例：

1. 点击“添加飞出子菜单”，中文文字填“音量快捷调节”。
2. 选中这个父菜单，点击“进入这个子菜单编辑”。
3. 点击“添加按钮”，动作选“ConVar 滑块”。
4. 中文文字填“游戏音量”，参数按第 6 节填写。
5. 继续添加其他滑块，确认“所属菜单”都是“音量快捷调节”。
6. 点击“应用并保存”。

添加元素时，它会放进当前正在编辑的菜单。只选中父按钮、不进入子菜单就添加，新元素不会自动归到这个父按钮下面。

已有元素可以通过“所属菜单”移动到其他菜单；选择“首页”后，它会成为首页元素。子菜单也可以再放飞出子菜单，但不能把自己或上级菜单归到自己下面。

子项可以拖动位置、调整大小；每页最多显示 8 项，超过后使用“上一页 / 下一页”。“返回上一级”和“首页”用于返回菜单，不需要自己添加返回按钮。

整套布局最多 128 个元素，首页按钮、文字、滑块、隐藏项和所有子项都计数；菜单层级最多 8 层。

5. 游戏动作与控制台命令

原生动作

选择对应动作即可，不用填写参数：

- 音频设置、视频设置、键盘 / 鼠标：直接打开对应原生设置页。
- 选项：打开原生完整设置子菜单，包含游戏当前提供的多人联机、Steam 云等入口。
- 闲置、邀请好友、统计与成就、附加内容。
- 原生发起投票：打开游戏自己的投票菜单。
- 踢出玩家、更改难度、开始新战役、重新开始战役、投票更换章节、返回大厅、更改全局语音：对应的原生投票或操作入口。
- 近期战报：打开与主菜单共用的战报网页。
- 断开连接：执行 disconnect。
- 快速退出：执行 quit，直接退出游戏。
- 本次使用原生 ESC 菜单：切换到这次打开的原生菜单。
- 继续游戏、Skeeto 设置：也可以按需要自行添加。

是否能发起某项投票、使用某项操作，由当前模式和服务器决定。打开原生设置或投票面板时，自绘按钮会让位给原生界面。

动作列表里还保留“发起投票”这个自定义子菜单容器。它与“原生发起投票”不同：前者需要自己放入投票子按钮，后者直接打开游戏的投票菜单。

控制台命令

动作选“控制台命令”，参数填写一整行命令，和在游戏控制台中输入的内容相同。例如：

volume 0
volume 0.5
connect 203.0.113.10:27015
exec my_settings.cfg
cl_showfps 1

依次表示静音、音量设为 50%、连接服务器、执行 cfg、显示 FPS。示例 IP 要换成自己的服务器地址；cfg 文件放在 left4dead2\cfg 中。

多条命令可以用分号隔开：

volume 0.5; snd_musicvolume 0.2

参数必须是单行，最多 191 个 UTF-8 字节；中文会占多个字节。导入或载入布局不会执行命令，正常使用时点击按钮才执行。

6. ConVar 滑块与会话滑块

两种滑块的参数格式相同：

变量名 最小值 最大值 步进
ps：当最大值与最小值相同时，可以把某个ConVar锁死在这个值，可以反过来利用这一点实现变量的强改。

点击“编辑动作参数”后，分别填写变量名、最小值、最大值和步进，再点击“应用这些参数”。最大值必须大于最小值，步进必须大于 0，且不大于整个范围。

例子：

volume 0 1 0.05
snd_musicvolume 0 1 0.05
sensitivity 0.1 10 0.1
skeeto_audio_gunfire_volume 0 100 5
cl_showfps 0 1 1

依次是游戏总音量、音乐音量、鼠标灵敏度、枪声音量和 FPS 显示。注意原版音量通常用 0～1，Skeeto 分类音量用 0～100。

普通 ConVar 滑块

拖动时通过普通控制台命令设值。换图、重新连接或服务器重新设置变量后，数值可能变化。

ConVar 会话滑块（skt_cvar）

这是与原版ESC菜单不同的一点。原版的ESC菜单通过菜单指令写入Cvar值，服务器内过关后带有cheat flag的值会被重置。Skeeto的ESC菜单使用skt_cvar写入，会持久化存储（持续一整个游戏进程，退出后或者进入竞技服务器失效）。
通过 Skeeto 的 skt_cvar 设值并保留本机记录。换图、换服后照常尝试重放，记录持续到本次游戏进程结束。服务器是否接受、最终数值是多少，仍以游戏实际结果为准。

这里的 skt_cvar 是命令，不是要填进变量名栏的 ConVar。使用会话滑块时，变量名仍填 volume、cl_showfps 这样的名称，不要填成 skt_cvar volume。

滑块需要变量在客户端存在且能读取。数值发灰或不可调整时，先在控制台输入变量名，确认它是否存在。服务端插件独有的变量不一定会同步到客户端。

7. 保存和执行 ConVar 预设

ConVar 预设保存变量值，布局方案保存按钮和排版，两者不是同一个东西。

使用默认的“ConVar 预设”按钮，或添加一个动作选“ConVar 预设”的按钮。此动作不用参数。

保存一套数值：

1. 先把需要的 ConVar 滑块放进布局，再调好数值。
2. 打开“ConVar 预设”，选择 1～8 中的一个槽位。
3. 点击“保存 / 覆盖所选槽：当前滑块值”。
4. 点击“命名 ConVar 预设”，填写容易识别的名字，例如“日常画面”“练习设置”。

保存范围是当前布局里的所有 ConVar 滑块，包括其他子菜单和隐藏项中的滑块，不限于当前正在看的这一页。相同变量只保存一份，每槽最多 64 个不同变量。无法读取的变量会跳过并提示；超过容量时不保存这一次。

以后选择槽位，点击“执行所选预设”即可。保存预设、切换所选槽位都不会自动执行。普通滑块按普通命令恢复，会话滑块按 skt_cvar 恢复。

预设文件会保存到磁盘，退出游戏后仍保留；会话设值记录只持续到游戏进程结束。下次启动后需要使用这套数值时，重新执行预设。

8. 服务器、地图和时间组件

这些组件也按元素编辑，可以单独隐藏、移动、缩放和改颜色。动作参数填写下面列出的英文词，不填中文说明。参数留空时使用该组件的默认显示方式。

局内服务器信息条

all：合并显示服务器、地图、延迟、人数和地址。
server：只显示服务器名称。
map：只显示地图代码。点击后可复制建图代码。
ping：只显示延迟。
players：只显示人数，分子只计算真人，不含 Bot。
address：只显示连接地址。点击后可复制ip连接。

默认布局把服名、延迟、人数和地址拆成四个独立元素，便于分别移动。想增加一个单独的延迟组件，添加按钮后选“局内服务器信息条”，参数填 ping 即可。

点击 address 或 all 组件，会复制 connect 加连接地址，例如：

connect 203.0.113.10:27015

只复制，不直接连接。部分服务器信息可能无法获取，地址也可能是本地连接地址；未获取的字段不会用猜测值填充。

战役 / 关卡 / 建图代码

all：显示战役名、关卡名和地图代码。
campaign：只显示战役名。
chapter：只显示关卡名。
code：只显示地图代码，例如 c1m1_hotel。

可读名称缺失时，对应字段回退到地图代码。显示内容不带 map 前缀；点击地图信息组件后，复制的是完整命令：

map c1m1_hotel

世界时间

time：显示本地时间，格式为 时:分:秒。
date：显示日期，格式为 年-月-日。
full：显示完整日期和时间。

世界时间使用电脑的本地时间，不是服务器时区。

本局计时

hms：显示本局经过的时、分、秒。
seconds：显示本局经过的总秒数。

计时沿用回合开始、结束的规则，暂停期间经过的时间也算在内，不是游戏内仿真时间。

9. HUD 与采集控制按钮

默认子菜单里有四个分项按钮，对应下面四条控制台命令：

skeeto_hud_toggle
skeeto_world_hud_toggle
skeeto_xhair_toggle
skeeto_hud_pause

依次切换自定义 HUD、世界 HUD、准星的总显示，以及数据采集的暂停状态。显示开关不改变各个子模块原来的设置。

用“控制台命令”动作，参数只填上述命令名，按钮会显示当前状态，例如“自定义 HUD [显示]”“数据采集 [已暂停]”。换成自己的按钮标题也能显示状态；任意其他命令不会自动出现状态文字。

需要做固定动作时，可以加 0 或 1：

skeeto_hud_toggle 1：隐藏自定义 HUD；0 为显示。
skeeto_world_hud_toggle 1：隐藏世界 HUD；0 为显示。
skeeto_xhair_toggle 1：隐藏准星；0 为显示。
skeeto_hud_pause 1：暂停；0 为恢复。

带固定参数的命令按钮不显示上述自动状态。采集总暂停时，自定义 HUD、世界 HUD 按钮也会标为“已暂停”。

默认“分类音量调节”里的“安全屋结算”和“雨爱”分别控制对应音乐音量。分类音量是否启用，也可以在该子菜单中调整。

10. 布局方案、备份和分享

布局文件都在游戏目录下面的：

left4dead2\skeeto\escmenu\

current.hud：当前正在使用的 ESC 布局。
profiles\slot1.hud ～ slot8.hud：编辑器里的 8 个布局方案槽位。
cvar_presets.bin：8 个 ConVar 数值预设，不是布局文件。

编辑器里的操作：

- 应用并保存：让当前草稿生效，并保存为 current.hud。
- 保存草稿到方案槽位：把草稿存进选中的槽位，按提示确认；不会替换当前使用的布局。
- 从方案槽位载入草稿：读入槽位中的布局，检查后还要“应用并保存”才生效。
- 打开方案文件夹：打开 profiles 文件夹。
- 草稿恢复默认布局：把草稿换成当前版本的默认预设；应用前仍可取消。

分享布局：先保存到一个方案槽位，再把对应的 slotN.hud 发给对方。

使用别人分享的布局：退出游戏，把文件复制到 profiles 文件夹，命名为 slot1.hud～slot8.hud 中准备使用的一个槽位；如果这个槽位已有方案，先留好自己的文件。重新进图后，在编辑器选择该槽位，载入草稿，检查并应用。

不要把主菜单或其他 HUD 的 .hud 文件改名当作 ESC 方案。不同版本的布局格式也可能不同，读取失败时不会自动改写原文件。

ConVar 预设需要另外分享 cvar_presets.bin，复制这个文件会替换整套 8 槽数值预设。只想分享按钮排版时，不用带它。

11. 控制台快捷键与常见问题

可绑定的命令：

skeeto_escmenu_native：打开原生 ESC 菜单。
skeeto_escmenu_home：打开 Skeeto ESC 菜单。
skeeto_escmenu_edit：打开编辑模式。

绑定示例，每行单独执行。示例键位会覆盖这些键原来的绑定，可以换成自己空闲的键：

bind F9 skeeto_escmenu_native
bind F10 skeeto_escmenu_home
bind F11 skeeto_escmenu_edit

ESC 菜单没有主菜单教程里那套强制 F3/F4/F5 绑定。需要固定快捷键时，自行 bind；这些绑定保存在游戏配置中，不跟随布局方案。

关闭整个自定义 ESC 菜单：

skeeto_escmenu 0

查看当前模块状态：

skeeto_escmenu status

改了却没有保存？

编辑器中的修改先进入草稿。返回游戏或暂离编辑不等于保存，完成后点击“应用并保存”。方案槽位与当前布局也要分清：存进槽位后，不会自动让该槽位生效。

子按钮出现在首页？

检查“所属菜单”。添加子项前先进入对应子菜单编辑，已有按钮则直接修改所属菜单。

想把按钮排成一列？

Ctrl 多选，统一宽高，再左边对齐；调好两端位置后用垂直等间距。拖动总是贴到别的位置时，按住 Alt 或关闭吸附。

滑块松手后又变回去？

先确认变量名和范围正确，再看控制台中的实际值。游戏或服务器可能重新设值；会话滑块会保留记录并尝试重放，但不能保证所有服务器接受。

改了文字颜色，背景没有一起变？

将当前按钮背景或统一背景设为“跟随文字颜色”。悬停框也有独立的“跟随当前按钮颜色”，两处不是同一个设置。
